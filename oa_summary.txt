Vector Distance Functions
• A fundamental operation in vector search is to be able to determine 
how close, or how similar vectors are to each other
• There are various mathematical distance functions of doing this:
• Euclidean Distance
• Manhattan Distance
• Cosine Distance 
• Dot Distance
• Hamming Distance
• To get the best vector similarity search results, you want to use the 
same distance function that the vector embedding models used
• Similarity search is a way to find similarities using a vector distance

audio, video or code)
• Vector embedding models tend to be much less resource 
intensive than LLMs

Vector Indexes | Neighbor Graph Vector Index
• Graph-based index where vertices represent vectors 
and edges between vertices represent similarity
• In-Memory only index – highly efficient for both 
accuracy and speed
CREATE VECTOR INDEX house_idx 
ON house_for_sale(house_vector)
ORGANIZATION INMEMORY NEIGHBOR GRAPH 
DISTANCE EUCLIDEAN;
• The DISTANCE clause is optional (the default is COSINE)
• As a rule of thumb, the distance function should be chosen 
based on the embedding model used to generate the vectors
